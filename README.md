# AI 网页业务操作（初版 v1）

基于 **Playwright Python** 的自然语言智能体应用（课程第 21 题）——**初版骨架**。

> 本版本（v1）目标是先打通一条端到端核心闭环：**查询可预约时段**。
> 「预约」「填报」将在后续迭代中加入（含提交前预览与用户确认、更多测试等），
> 迭代完成后的最终形态见 `ai-web-operation`（本仓库后续提交）。

## 当前能力（v1）

- 支持 1 类自然语言意图：**查询**某日可预约时段（例如「查询明天可预约时段」）。
- 底层确定性操作由 Playwright 完成：访问本地模拟业务网站并返回精简时段表（不抓整页 HTML）。
- 「预约」「填报」两类意图已能识别，但明确返回“后续迭代支持”的提示（不静默乱做）。

## 运行

```bash
# 终端 1：启动本地模拟业务网站（默认 http://127.0.0.1:5099）
python mock_site/app.py

# 终端 2：自然语言端到端（初版仅查询可用）
python -m web_agent.cli agent --base http://127.0.0.1:5099 --text "查询明天可预约时段"

# 单步 CLI
python -m web_agent.cli query --base http://127.0.0.1:5099 --date 2026-09-09
```

首次运行需：`pip install -r requirements.txt` + `playwright install chromium`。

## 测试

```bash
pytest -v
```
